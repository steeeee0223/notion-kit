## 規格覆蓋檢查

- [ ] Month：完整週列、跨週橫條、多事件增高與只有垂直捲動。
- [ ] Week、Day：全天區、小時標籤、整點和半小時隔線、重疊事件。
- [ ] 瀏覽：共用 property、range、anchorDate，fallback 只在不支援時發生。
- [ ] 日期：時區、午夜、DST、包含式全天 end 與空 end。
- [ ] 編輯：原子新增、開啟、移動、雙端拉伸與全天互轉。
- [ ] 邊界：受控拒絕、鎖定、取消、外部更新和手勢失效。
- [ ] 公開 API：獨立 Calendar 可用，共用通用控制項未公開，日期 picker 不受影響。
- [ ] 回歸：Timeline 導覽、初始化、拖曳與拉伸仍正常。
- [ ] 文件：Registry、Storybook、Calendar 文件與 Table API 遷移對照一致。
