---
title: Autocomplete
description: A Base UI autocomplete composed with Notion-style menu groups, items, labels, and separators.
---

<RegistryStory name="autocomplete-default" />

```tsx
<Autocomplete items={groups} open autoHighlight="always" openOnInputClick>
  <AutocompleteInput placeholder="Search workspace..." />
  <AutocompleteContent>
    <AutocompleteEmpty>No matches found.</AutocompleteEmpty>
    <AutocompleteList>
      {(group) => (
        <AutocompleteGroup key={group.label} items={group.items}>
          <AutocompleteLabel title={group.label} />
          <AutocompleteCollection>
            {(item) => (
              <AutocompleteItem
                key={item}
                value={item}
                label={item}
                icon={group.icon}
              >
                <MenuItemAction className="text-xs text-muted">
                  {group.label.slice(0, -1)}
                </MenuItemAction>
              </AutocompleteItem>
            )}
          </AutocompleteCollection>
        </AutocompleteGroup>
      )}
    </AutocompleteList>
  </AutocompleteContent>
</Autocomplete>
```

### Popover Menu

Use `AutocompleteContent variant="inline"` when another primitive owns the overlay positioning. This keeps existing popover menus as `Popover` + `Autocomplete`.

<RegistryStory name="autocomplete-popover" />

```tsx
<Popover>
  <PopoverTrigger
    render={
      <Button variant="hint" size="sm">
        Open menu
      </Button>
    }
  />
  <PopoverContent>
    <Autocomplete items={groups} open autoHighlight="always" openOnInputClick>
      <AutocompleteInput placeholder="Search workspace..." />
      <AutocompleteContent variant="inline">
        <AutocompleteEmpty>No matches found.</AutocompleteEmpty>

            <AutocompleteGroup key={group.label} items={group.items}>
              <AutocompleteLabel title={group.label} />

                  <AutocompleteItem
                    key={item}
                    value={item}

                    <MenuItemAction className="text-xs text-muted">
                      {group.label.slice(0, -1)}
                    </MenuItemAction>
                  </AutocompleteItem>
                )}
              </AutocompleteCollection>
            </AutocompleteGroup>

  </PopoverContent>
</Popover>
```

### AutocompleteInput

The search input uses Base UI Input and Clear. It includes a search icon and shows the native clear button when the input has text. Use an uncontrolled root unless the query also drives application behavior.

`default` renders a bordered field with inset spacing. `flat` renders a full-width header with a bottom divider. Both styles include the search icon and native clear button.

      type: "string",

    },

Other input props, including `ref`, `render`, and accessible labels, follow Base UI Input. `AutocompleteInputProps` exports this contract.

The former `search`, `clear`, and `onCancel` props and standalone `AutocompleteClear` export are removed. Observe changes through the root's `onValueChange` when the application needs the query. Native clearing uses that same callback.

### AutocompleteEmpty

Content shown only when Base UI reports an empty filtered result set.
