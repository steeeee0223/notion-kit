
### Search Input

<RegistryStory name="input-search" />

```tsx
<Input
  className="w-80"
  value={value}
  onChange={(e) => setValue(e.target.value)}
  onCancel={() => setValue("")}
  placeholder="Enter something..."
  search
  clear
/>
```
