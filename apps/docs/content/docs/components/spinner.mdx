## Options

---

### Variant

Use the `variant` prop to control the visual style of the spinner.<br/>
The default variant is `"solid"`.

<SpinnerVariantsStory.WithControl />

```tsx
<Spinner variant="solid" />
  <Spinner variant="dashed" />
```

## API Reference

### Spinner

| Prop      | Type                  | Default   | Description                      |
| --------- | --------------------- | --------- | -------------------------------- |
| `variant` | `"solid" \| "dashed"` | `"solid"` | The visual style of the spinner. |
