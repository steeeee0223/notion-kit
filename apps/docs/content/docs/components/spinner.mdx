## Options

### Variant

Use the `variant` prop to control the visual style of the spinner.<br/>
The default variant is `"solid"`.

<RegistryStory name="spinner-variants" />

```tsx
<Spinner variant="solid" />
  <Spinner variant="dashed" />
```
