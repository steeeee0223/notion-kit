The preview uses `AlertModal` for a confirmation action with a loading indicator.

```tsx
import { useState } from "react";

import { AlertModal } from "@notion-kit/ui/alert-modal";
import { Button, Dialog, DialogTrigger } from "@notion-kit/ui/primitives";

export default function ConfirmationDialog() {
  const [open, setOpen] = useState(false);
  return (
    <Dialog open={open} onOpenChange={setOpen}>
      <DialogTrigger render={<Button size="md">Open</Button>} />
      <AlertModal
        title="This action cannot be undone. This will permanently delete your account and remove your data from our servers."
        primary="Continue"
        secondary="Cancel"
        onTrigger={async () => {
          await new Promise((resolve) => setTimeout(resolve, 1500));
          setOpen(false);
        }}
      />
    </Dialog>
  );
}
```

## Anatomy

`Dialog` owns the open state. `DialogTrigger` opens the popup, and `DialogClose` closes it.
`DialogContent` includes the portal, overlay, and a close button.
An extra `DialogPortal` or `DialogOverlay` is unnecessary when using `DialogContent`.

`DialogTitle` supplies the accessible name. `DialogDescription` supplies the description when the popup has explanatory text.

## Examples

### Custom content

This dialog manages its own open state. The footer supplies a custom close action in place of the default close button.

```tsx
import {
  Button,
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@notion-kit/ui/primitives";

<Dialog>
  <DialogTrigger render={<Button size="md">View details</Button>} />
  <DialogContent hideClose>
    <DialogHeader>
      <DialogTitle>Workspace details</DialogTitle>
      <DialogDescription>
        Manage the settings for this workspace.
      </DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose render={<Button size="md">Done</Button>} />
    </DialogFooter>
  </DialogContent>
</Dialog>;
```

### Other parts

These parts retain their underlying props:

- `DialogTrigger` accepts Base UI's `Dialog.Trigger` props. Its `render` prop composes with `Button`.
- `DialogClose` accepts Base UI's `Dialog.Close` props. It renders `CloseButton` unless `render` supplies a replacement.
- `DialogPortal` and `DialogOverlay` accept Base UI's portal and backdrop props.
- `DialogHeader`, `DialogFooter`, and `DialogIcon` accept HTML `<div>` props and provide layout styles.

### AlertModal

Imported from `@notion-kit/ui/alert-modal`. Renders confirmation content inside a parent `Dialog`, including a title and two action buttons.
The primary action displays a spinner while `onTrigger` is pending. The secondary action closes the dialog.
Resolving `onTrigger` does not close the dialog automatically.
