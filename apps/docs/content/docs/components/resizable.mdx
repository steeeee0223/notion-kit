## API Reference

### ResizablePanelGroup

Use `orientation="horizontal"` or `orientation="vertical"` to choose the resize axis.

### ResizablePanel

Use explicit percentages such as `defaultSize="50%"` for proportional layouts.
Numeric sizes such as `defaultSize={200}` are measured in pixels.
