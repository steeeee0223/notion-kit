## Anatomy

Compose the Base UI tooltip parts directly when you need custom content or
positioning. Use `render` to merge the trigger behavior into your button.

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button>Open search</Button>} />
    <TooltipContent>
      {...}
    </TooltipContent>
  </Tooltip>
</TooltipProvider>
```

`TooltipDescription` supports primary text, secondary text, and images:

```tsx
<TooltipContent>
  <TooltipDescription text="Open search" />
  <TooltipDescription type="secondary" text="⌘ K" />
  <TooltipDescription type="image" text="/search-preview.png" />
</TooltipContent>
```

## API Reference

### TooltipProvider

Uses [Base UI provider props](https://base-ui.com/react/components/tooltip#provider).
The default [`delay`](https://base-ui.com/react/components/tooltip#TooltipProvider-delay)
is `600` milliseconds. Use
[`timeout`](https://base-ui.com/react/components/tooltip#TooltipProvider-timeout)
to control how long subsequent tooltips skip the opening delay.

### Tooltip

Uses [Base UI root props](https://base-ui.com/react/components/tooltip#root),
including [`open`](https://base-ui.com/react/components/tooltip#TooltipRoot-open)
and [`onOpenChange`](https://base-ui.com/react/components/tooltip#TooltipRoot-onOpenChange).

### TooltipTrigger

Uses [Base UI trigger props](https://base-ui.com/react/components/tooltip#trigger).
Pass a React element to
[`render`](https://base-ui.com/react/components/tooltip#TooltipTrigger-render)
to avoid adding a wrapper around the trigger.

### TooltipContent

Accepts [Base UI popup props](https://base-ui.com/react/components/tooltip#popup)
plus [`align`](https://base-ui.com/react/components/tooltip#TooltipPositioner-align),
[`alignOffset`](https://base-ui.com/react/components/tooltip#TooltipPositioner-alignOffset),
[`anchor`](https://base-ui.com/react/components/tooltip#TooltipPositioner-anchor),
[`collisionPadding`](https://base-ui.com/react/components/tooltip#TooltipPositioner-collisionPadding),
[`side`](https://base-ui.com/react/components/tooltip#TooltipPositioner-side), and
[`sideOffset`](https://base-ui.com/react/components/tooltip#TooltipPositioner-sideOffset).
Its default `sideOffset` is `4`.
