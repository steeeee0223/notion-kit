## Options

### Size

Use the `size` prop to control the size of the checkbox.
The default size is `"md"`.

<RegistryStory name="checkbox-sizes" />

```tsx
<Checkbox size="xs"/>
  <Checkbox size="sm"/>
  <Checkbox size="md"/>
```
