## API Reference

### Kbd

`Kbd` extends the HTML `<kbd>` component.

### KbdGroup

`KbdGroup` extends the HTML `<span>` component and renders `role="group"`.
Give it an `aria-label` describing the shortcut, e.g. `"Command K"`.
