## API Reference

### EmptyState

`EmptyState` extends the HTML `<div>` component.

| Prop          | Type          | Default | Description                                       |
| ------------- | ------------- | ------- | --------------------------------------------------- |
| `icon`        | `ReactNode`   | -       | An icon rendered above the title.                    |
| `title`       | `ReactNode`   | -       | The heading. Required.                               |
| `description` | `ReactNode`   | -       | Supporting text below the title.                     |
| `actions`     | `ReactNode`   | -       | Buttons or links rendered below the description.     |
| `size`        | `"sm" \| "md"` | `"md"`  | Controls spacing and icon/title sizing.              |
