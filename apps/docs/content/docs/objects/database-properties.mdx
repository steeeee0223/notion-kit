---
title: Database Properties
description: Database property objects are rendered in the Notion UI as database columns.
---

Database properties are represented as columns in the Notion database. They are defined by [`CellPlugin`](/docs/blocks/table-view/cell-plugins)'s that specify how the property behaves and renders in the Notion UI.

## ColumnInfo

A database column object `ColumnInfo<TPlugin>` consists of the common properties and the plugin-specific configuration.

## ColumnDefs

A `ColumnDefs` is an array of column definitions `ColumnInfo<TPlugin>` where the `config` property may be optional.

```ts
const columnDefs: ColumnDefs = [
  {
    id: "col-1",
    name: "Title",
    type: "title",
    // the `config` optional
    config: { showIcon: true },
  },
];
```

## Cell

A `Cell<TPlugin>` contains the `id` and `value`, where the value is determined by the plugin’s data type.

### Common Properties

<TypeTable
  type={{
    id: {
      type: "string",
      required: true,
      description: "Unique identifier of the cell.",
    },
    value: {
      type: "InferData<TPlugin>",
      required: true,
      description: "Plugin-defined cell data.",
    },
  }}
/>

### Examples

#### Title Cell

```ts
// Cell<TitlePlugin>
{
  id: "e79a0b74-3aba-4149-9f74-0bb5791a6ee6",
  value:  "New title",
}
```

#### Text Cell

```ts
// Cell<TextPlugin>
{
  id: "e79a0b74-3aba-4149-9f74-0bb5791a6ee6",
  value: "Some text..."
}
```

#### Checkbox Cell

```ts
// Cell<CheckboxPlugin>
{
  id: "e79a0b74-3aba-4149-9f74-0bb5791a6ee6",
  value: true,
}
```
