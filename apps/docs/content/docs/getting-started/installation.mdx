## Create Project

Run the `shadcn init` command to create a new Next.js project or to setup an existing one:

```bash
pnpm dlx shadcn@latest init
```

Choose between a Next.js project or a Monorepo.

## Setup Notion UI styles

Add the CSS import to the top of your global stylesheet (e.g., `app/globals.css`):

```css
@import "tailwindcss";
@import "@notion-kit/ui/style.css"; // [!code highlight]
```

## Add Notion Components

Install the UI package to use Notion Kit primitives and blocks:

```bash
pnpm add @notion-kit/ui
```

You can then import the primitives:

```tsx
import { Button } from "@notion-kit/ui/primitives";

export default function Home() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  );
}
```

To copy an example into your project, use its registry installation command:

```bash
pnpm dlx shadcn@latest add https://notion-ui.vercel.app/registry/button-default.json
```

Browse the [registry examples](/registry) for individual installation commands.
