The preview renders `WorkspaceSwitcherMenu` with sample workspaces. In your app, use `WorkspaceSwitcher` inside an [Auth Provider](/docs/auth-ui/auth-provider). The switcher reads the signed-in account and workspaces, updates the active workspace, and signs the user out. Users can open the menu and choose a workspace before their session has an active workspace.

```tsx
import { AuthProvider, WorkspaceSwitcher } from "@notion-kit/auth-ui";

<AuthProvider authURL="https://auth.example.com">
  <WorkspaceSwitcher
    onWorkspaceChange={({ slug }) => {
      window.location.assign(`/workspace/${encodeURIComponent(slug)}`);
    }}
  />
</AuthProvider>;
```

## API reference

Use the callbacks to wire app-specific navigation and dialogs. The switcher calls `onWorkspaceChange` and `onSignedOut` after the corresponding auth operation succeeds.
