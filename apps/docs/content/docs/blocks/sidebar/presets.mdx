title: Sidebar presets

## Installation

```package-install
pnpm add @notion-kit/ui
```

## Components

### Workspace switcher

Use the [Workspace Switcher](/docs/auth-ui/workspace-switcher) from `@notion-kit/auth-ui` to switch workspaces and sign out in an authenticated sidebar.

### Page list

Use `DocList` to display pages in a named group.

<RegistryStory name="sidebar-page-list" />

```tsx
<DocList group="document" title="Document" pages={pages} />
```

#### API reference

<TypeTable
  type={{
    group: {
      type: "string",
      required: true,
      description: "The identifier of the group.",
    },
    title: {
      type: "string",
      required: true,
      description: "The group title.",
    },
    pages: {
      type: "Page[]",
      typeDescriptionLink: "/docs/objects/page",
      required: true,
      description: "Pages in this group.",
    },
    activePage: {
      type: "string | null",
      description: "The active page in this group.",
    },
    defaultIcon: {
      type: "IconData",
      typeDescriptionLink: "/docs/objects/icon",
      default: '{ type: "lucide", src: "file" }',
      description:
        "The default icon of the page within this group. This is useful when a page has no icon selected.",
    },
    onSelect: {
      type: "(page: Page) => void",
      parameters: [
        {
          name: "page",
          type: "Page",
          description: "The selected page.",
        },
      ],
      returns: "void",
      description: "Called when the user selects a page.",
    },
    onCreate: {
      type: "(group: string, parentId?: string) => void",
      parameters: [
        {
          name: "group",
          type: "string",
          description: "The page group identifier.",
        },
        {
          name: "parentId?",
          type: "string",
          description:
            "Optional. The parent page ID, when creating a nested page.",
        },
      ],
      returns: "void",
      description: 'Called when the user chooses "Create" in this group.',
    },
    onDuplicate: {
      type: "(id: string) => void",
      parameters: [
        {
          name: "id",
          type: "string",
          description: "The target page ID.",
        },
      ],
      returns: "void",
      description: 'Called when the user chooses "Duplicate".',
    },
    onUpdate: {
      type: "(id: string, data: UpdatePageParams) => void",
      parameters: [
        {
          name: "id",
          type: "string",
          description: "The target page ID.",
        },
        {
          name: "data",
          type: "UpdatePageParams",
          description: "The page fields to update.",
        },
      ],
      returns: "void",
      description: "Called with the fields changed by a page action.",
    },
  }}
/>

### Trash box

<RegistryStory name="sidebar-trash-box" />

```tsx

```
