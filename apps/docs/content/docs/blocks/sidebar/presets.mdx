### Workspace Switcher

A `WorkspaceSwitcher` is a dropdown menu that controls workspaces and user's login state.

<RegistryStory name="sidebar-workspace-switcher" />

```tsx
<WorkspaceSwitcher
  user={user}
  workspaces={workspaces}
  activeWorkspace={activeWorkspace}
/>
```

#### API Reference

  type={{

      type: "User",

      description: "Current user.",
    },
    activeWorkspace: {
      type: "Workspace",
      typeDescriptionLink: "/docs/objects/workspace",
      required: true,
      description: "Current user.",
    },
    workspaces: {
      type: "Workspace[]",
      typeDescriptionLink: "/docs/objects/workspace",
      required: true,
      description: "Current user.",
    },
    onSelect: {
      type: "(id: string) => void",
      parameters: [
        {
          name: "id",

      returns: "void",
      description: "Handler that is called when a workspace is selected.",
    },
    onCreateAccount: {
      type: "() => void",
      returns: "void",

    },
    onCreateWorkspace: {

        'Handler that is called when the "Logout" button is clicked.',

### Page List

A page list is a component `DocList` showing a group of pages.

<RegistryStory name="sidebar-page-list" />

```tsx
<DocList group="document" title="Document" pages={pages} />
```

#### API Reference

  type={{

    pages: {
      type: "Page[]",
      typeDescriptionLink: "/docs/objects/page",

    activePage: {
      type: "string | null",

      type: "(page: Page) => void",
