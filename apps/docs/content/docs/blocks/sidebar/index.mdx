## Anatomy

```tsx
<SidebarProvider>
  <Sidebar>
    <SidebarClose />
    <SidebarHeader>{/* Your sidebar header */}</SidebarHeader>
    <SidebarContent>{/* Your sidebar content */}</SidebarContent>
    <SidebarFooter>{/* Your sidebar footer */}</SidebarFooter>
    <SidebarRail />
  </Sidebar>
  <SidebarInset>{/* Your main content */}</SidebarInset>
</SidebarProvider>
```

### Sidebar

`Sidebar` accepts HTML `<div>` props and the props below.

<TypeTable
  type={{
    side: {
      type: '"left" | "right"',
      default: '"left"',
      description: "The side of the sidebar.",
    },
    variant: {
      type: '"sidebar" | "floating"',
      default: '"sidebar"',
      description: "The variant of the sidebar.",
    },
    collapsible: {
      type: '"offcanvas" | "none"',
      default: '"offcanvas"',
      description: "Collapsible state of the sidebar.",
    },
  }}
/>

### SidebarHeader

A `SidebarHeader` extends the HTML `<div>` element.

### SidebarContent

A `SidebarContent` extends the HTML `<div>` element.

### SidebarFooter

A `SidebarFooter` extends the HTML `<div>` element.

### SidebarGroup

A `SidebarGroup` extends the HTML `<div>` element.

### SidebarInset

A `SidebarInset` extends the HTML `<main>` element.

### SidebarRail

Use `SidebarRail` inside `Sidebar` to toggle or resize it.
It accepts HTML `<div>` props and the props below.

<TypeTable
  type={{
    enableDrag: {
      type: "boolean",
      default: "true",
      description: "Whether the sidebar is draggable.",
    },
  }}
/>

### SidebarClose

`SidebarClose` is a button that closes the sidebar. The keyboard shortcut can also close it.

### SidebarOpen

`SidebarOpen` is a button that opens the sidebar. The keyboard shortcut can also open it.

### SidebarMenuItem

`SidebarMenuItem` accepts HTML `<div>` props and the props below.
