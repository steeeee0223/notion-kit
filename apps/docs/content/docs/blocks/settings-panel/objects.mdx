## Cell Options

A `CellOptions` is a generic type `CellOptions<T>`, where `T` extends `{ id: string }`.

### Properties

<TypeTable
  type={{
    current: {
      type: "string | null",
      required: true,
      description: (
        <>
          {" "}
          The unique identifier of current option, i.e.{" "}
          <code>options[i].id</code>{" "}
        </>
      ),
    },
    options: {
      type: "T[]",
      required: true,
      description: "Available options.",
    },
  }}
/>

### Example

An example for `CellOptions<{ id: string, title: string }>`

```ts
{
  current: "a",
  options: [
    { id: "a", title: "A" },
    { id: "b", title: "B" },
    { id: "c", title: "C" },
  ]
}
```
