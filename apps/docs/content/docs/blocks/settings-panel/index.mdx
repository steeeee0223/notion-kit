title: Settings Panel
description: Account and workspace settings with member, billing, and connection management.

<RegistryStory name="settings-panel-notion" />

## Supported Features

- Account settings
  - Update/delete account
  - Change password
  - Device sessions
  - Passkeys management
  - Link social accounts
- Theme select
- Localization support for `EN`, `DE`, `ES`
- Timezone support
- Workspace settings
  - Update/delete/leave workspace
  - Members & scopes management
  - Teamspaces management
- Billing
  - Payment method, billing address, billing email
  - Plan upgrade / change
  - Stripe integration
- Custom emoji management
- Workspace icon upload
