## Installation

```package-install
pnpm add @notion-kit/ui
```

## Components

---

### Title

<NavbarTitleStory.WithControl />

```tsx
<Title page={page} />
```

#### API Reference

| Prop       | Type                                            | Default | Description                                                 |
| ---------- | ----------------------------------------------- | ------- | ----------------------------------------------------------- |
| `page`\*   | [`Page`](/docs/objects/page)                    | -       | Current page data.                                          |
| `readOnly` | `boolean`                                       | -       | Whether the title is editable.                              |
| `onUpdate` | `({ title?: string, icon?: IconData }) => void` | -       | Handler that is called when new title or icon is submitted. |

### Sharing

<NavbarSharingStory.WithControl />

```tsx
<TooltipProvider>
  <Publish page={page} />
</TooltipProvider>
```

#### API Reference

| Prop       | Type                                         | Default | Description                                                          |
| ---------- | -------------------------------------------- | ------- | -------------------------------------------------------------------- |
| `page`\*   | [`Page`](/docs/objects/page)                 | -       | Current page data.                                                   |
| `onUpdate` | `(id: string, isPublished: boolean) => void` | -       | Handler that is called when the public state of the page is changed. |

### Menu

<NavbarMenuStory.WithControl />

```tsx
<TooltipProvider>
  <Menu page={page} />
</TooltipProvider>
```

#### API Reference

| Prop       | Type                                                                   | Default | Description                                                         |
| ---------- | ---------------------------------------------------------------------- | ------- | ------------------------------------------------------------------- |
| `page`\*   | [`Page`](/docs/objects/page)                                           | -       | Current page data.                                                  |
| `onUpdate` | `(pageId: string, action: "archive" \| "restore" \| "delete") => void` | -       | Handler that is called when an action is triggered from a menuitem. |

### Participants

<NavbarParticipantsStory.WithControl />

```tsx
<TooltipProvider>
  <Participants currentUser={currentUser} otherUsers={otherUsers} />
</TooltipProvider>
```

#### API Reference

| Prop          | Type                         | Default | Description                  |
| ------------- | ---------------------------- | ------- | ---------------------------- |
| `currentUser` | [`User`](/docs/objects/user) | -       | Current user, i.e. yourself. |
| `otherUsers`  | `User[]`                     | `[]`    | Other users on the page.     |
