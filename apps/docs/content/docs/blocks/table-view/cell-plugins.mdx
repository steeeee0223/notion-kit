---
title: Cell Plugins
description: Define a table property's data semantics and its matching UI adapter.
---

A custom property is registered as a matched pair: a pure
`CellPlugin<Key, Data, Config>` from `@notion-kit/table-hook` and a
`TableUiPlugin` from `@notion-kit/table-view`. Both use the same property type
ID.

## Data plugin definition

| Field                                          | Description                                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `id`                                           | Unique property type identifier.                                                                 |
| `default`                                      | Default cell data and property configuration.                                                    |
| `fromValue`                                    | Converts a comparable value into cell data.                                                      |
| `toValue`                                      | Converts cell data for sorting and grouping.                                                     |
| `toGroupValue`                                 | Optionally converts cell data to a grouping value; falls back to `toValue`.                      |
| `isEmpty`                                      | Defines empty data for filters, counts, sorting, and grouping.                                   |
| `toTextValue`                                  | Converts cell data to copyable text.                                                             |
| `sorting`, `grouping`, `counting`, `filtering` | Optional pure data capabilities discovered by table menus.                                       |
| `compare`                                      | Legacy row comparator used as a sorting fallback when no registered sorting method resolves.     |
| `transferConfig`                               | Optionally derives configuration when a property changes to this type, using its existing rows.   |

Data plugins do not render React, carry icons, or decide cell presentation.

## UI adapter definition

| Field                 | Description                                                     |
| --------------------- | --------------------------------------------------------------- |
| `id`                  | Must match the data plugin ID.                                  |
| `meta`                | Type-menu name, description, and icon.                          |
| `default`             | Default property name, icon, and optional width.                |
| `renderCell`          | **Required.** Returns the complete React UI for a cell surface. |
| `renderBulkEditor`    | Optional. Its presence enables bulk editing.                    |
| `renderConfigMenu`    | Optional property configuration UI.                             |
| `renderGroupingValue` | **Required.** Returns the grouped label UI.                     |

`renderCell` receives `CellProps`, containing only a TanStack `cell` instance.
Use `cell.getInfo()`, `cell.getPlugin()`, `cell.getData()`,
`cell.getTextValue()`, and `cell.update()` to read and change the cell.
`renderBulkEditor` and `renderConfigMenu` receive `BulkEditorProps` and
`ConfigMenuProps`, each containing only a TanStack `column` instance. The
column exposes `getInfo()`, `getPlugin()`, `getSelectedRowIds()`, `getCell()`,
`updateCells()`, and `updateConfig()`. Adapters own their triggers, popovers,
empty states, copy affordances, and layout classes.

## Registration

```tsx
const plugins = {
  data: [tagPlugin],
  ui: [tagPluginUi],
};

<TableView plugins={plugins} />;
```

The registry rejects missing, duplicate, and unmatched IDs. There is no
combined-plugin registration path.

## Types

| Type                            | Description                                      |
| ------------------------------- | ------------------------------------------------ |
| `CellPlugin<Key, Data, Config>` | Pure table-hook data semantics and capabilities. |
| `TableUiPlugin<TPlugin>`        | React adapter coupled to one data plugin.        |
| `CellProps`                     | A TanStack cell instance for direct rendering.   |
| `BulkEditorProps`               | A TanStack column instance for bulk rendering.   |
| `ConfigMenuProps`               | A TanStack column instance for configuration UI. |
