title: Cell Plugins
description: Define a table property's data semantics and its matching UI adapter.

A custom property is registered as a matched pair: a pure
`CellPlugin<Key, Data, Config>` from `@notion-kit/table-hook` and a
`TableUiPlugin` from `@notion-kit/table-view`. Both use the same property type
ID.

`renderCell` receives `CellProps`, containing only a TanStack `cell` instance.
Use `cell.getInfo()`, `cell.getPlugin()`, `cell.getData()`,
`cell.getTextValue()`, and `cell.update()` to read and change the cell.
`renderBulkEditor` and `renderConfigMenu` receive `BulkEditorProps` and
`ConfigMenuProps`, each containing only a TanStack `column` instance. The
column exposes `getInfo()`, `getPlugin()`, `getSelectedRowIds()`, `getCell()`,
`updateCells()`, and `updateConfig()`. Adapters own their triggers, popovers,
empty states, copy affordances, and layout classes.

## Read-only history renderers

`renderReadOnlyValue` is optional. Existing adapters remain compatible and use
the record's `textValue` when the renderer is absent. The renderer receives
`ReadOnlyValueProps`:

<TypeTable
  type={{
    value: {
      type: "unknown",
      description: "Historical cell value, typed as unknown.",
      required: true,
    },
    config: {
      type: "unknown",
      description: "Historical property configuration, typed as unknown.",
      required: true,
    },
    property: {
      type: 'RowEditLog["property"]',
      description:
        "Historical ID, name, icon, type, and optional configuration.",
      required: true,
    },
    textValue: {
      type: "string",
      description: "Historical plain-text representation used for fallback.",
      required: true,
    },
  }}
/>

Validate the snapshot with Zod before rendering it. Return `textValue` when the
value or configuration is unsupported. Return **Empty** for an empty value;
keep false checkboxes and numeric zero visible. A text adapter can provide:

```tsx
import { z } from "zod";

import type { ReadOnlyValueProps } from "@notion-kit/table-view";

function HistoricalText({ value, textValue }: ReadOnlyValueProps) {
  const result = z.string().safeParse(value);
  if (!result.success) return textValue;
  return (
    <span className="wrap-anywhere whitespace-pre-wrap">
      {result.data || "Empty"}
    </span>
  );
}

// In the UI adapter:
// renderReadOnlyValue: (props) => <HistoricalText {...props} />
```

A renderer receives no table, cell, editor, or mutation callback. It uses only
the stored metadata, even after the current property or an option is renamed,
reconfigured, or removed. Keep it read-only and reuse your value component
without mounting its editor. Built-in adapters follow this contract for text,
tags, checkboxes, numbers, links, dates, and resolved timestamps.

Unknown property types use `textValue`. A rendering error is isolated to the
individual value and also shows `textValue`; other records remain visible.

## Registration

```tsx
const plugins = {
  data: [tagPlugin],
  ui: [tagPluginUi],
};

<TableView plugins={plugins} />;
```

The registry rejects missing, duplicate, and unmatched IDs. There is no
combined-plugin registration path.
